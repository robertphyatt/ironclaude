# v1.1.16 Roadmap

> **Created:** 2026-10-02
> **Decision:** the operator chose to fold the Codex proportionality and client-parity fixes into v1.1.16. The work is delivered as several smaller PM loops, each with its own review and commit, and ships together as one v1.1.16 release.

## Constraints that apply to every loop

- **One IronClaude.** Claude and Codex must behave the same. There are no client-specific behavior forks; provider plumbing (tool names, the advisor broker, model ladders) is the only exception.
- **The workflow banner stays word for word.** "No small or trivial exceptions" forbids skipping stages. It does not license extra work.
- **Git handling.**
  - No commit trailers.
  - No push without an explicit go for that push.
  - No GitHub CI; use local suites.
