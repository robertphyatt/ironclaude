# M6 — `/close-out` human verb Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use ironclaude:executing-plans to implement this plan task-by-task.

**Goal:** Add the `/close-out` human verb (verb 4): integrate the managed worktree's HEAD into LOCAL
main, then fully tear the worktree down — auto-resolving push-pending obligations (carry forward),
dirty trees (recovery-ref snapshot), and mechanically-recoverable paused rebases (handler-orchestrated
auto-continue), never handing work back to the operator.

**Requirements:** docs/plans/2026-08-26-m6-close-out-requirements.md

**Architecture:** close-out is a managed-only direct-Git verb whose intent is EVIDENCE-LIGHT at issuance
(binds branch identity from `assignment.branch`, no HEAD read — so it mints on active/ready/detached/
integrated rows) and whose MCP handler ORCHESTRATES paused-rebase recovery (`reconcileFinalization`
status→continue, authority-free) BEFORE verifying authority; then `finalizeCloseOut` (active / ready-frozen
/ integrated branches) ends in `closeOutRelease` (carry-obligation teardown). reconcile/commit/
commit-and-push/push lanes stay byte-untouched; `reconcileFinalization`/`releaseFinalized`/
`recoverRebaseInProgress` are reused UNMODIFIED. Design: docs/plans/2026-08-26-m6-close-out-design.md.

**Tech Stack:** TypeScript, vitest, better-sqlite3, git; a bash UserPromptSubmit hook.

**Execution invariants (declared for the reviewer):** absolute paths; `docs/` gitignored (`git add -f`);
ALL vitest commands use `--testTimeout=30000` (no vitest.config; 5s default flakes git tests); test git
helper is `git()` not `runGit`; inline `SELECT` row reads; `runGit` uses `spawnSync` (git.ts:28) — a new
`runGitEnv` mirrors that (NOT execFileSync); `decodePushDisposition` is private to integration.ts (a
shared predicate is exported only in Task 7); `consumeMatchingHumanIntent` (db.ts:567) matches on exact
`expected_evidence` JSON equality, so the close-out intent's issue and verify MUST produce the identical
HEAD-independent branch-only evidence; the guard's `\bgit\b.*\b(commit|push)\b` block matches those words
as PATH substrings (the `close-out`/`close_out` names avoid it); the suite run is each task's falsifier.

```typescript
function closeOutRelease(db, repositoryPath, assignment, recovery?): FinalizationResult {
  const current = getAssignment(db, assignment.workspace_guid);
  if (!current || current.lifecycle_status !== 'integrated' || !current.integrated_commit)
    throw new Error('Close-out release requires a durable integrated assignment; preserving worktree');
  if (!worktreeIsClean(current.worktree_path))
    throw new Error('Close-out release requires a clean worktree; preserving worktree');
  const ref = targetRef(current);
  const actualHead = worktreeHead(current.worktree_path);
  const integration = db.prepare(`SELECT target_ref, integrated_commit FROM integration_records WHERE workspace_guid = ? AND repository_identity = ?`).get(current.workspace_guid, current.repository_identity);
  if (!integration || integration.target_ref !== ref || integration.integrated_commit !== current.integrated_commit || actualHead !== current.integrated_commit || !isAncestor(repositoryPath, current.integrated_commit, ref))
    throw new Error('Close-out integration proof is unreachable from the integration target; preserving worktree');
  removeWorktree(repositoryPath, current.worktree_path);
  deleteTemporaryBranch(repositoryPath, current.branch);
  transitionAssignment(db, current.workspace_guid, 'integrated', 'cleaned');
  return { state: 'closed-out', integratedCommit: current.integrated_commit, ...(recovery ? { recovery } : {}) };
}
```

**Step 3: GREEN — `finalizeCloseOut` with three lifecycle branches**

```typescript
const usedCloseOutAuthorities = new WeakSet<AuthorizedDirectGitOperation>();
export function finalizeCloseOut(db, authority): FinalizationResult {
  if (authority.operation !== 'close-out') throw new Error('Close-out finalization requires close-out authority');
  if (authority.checkoutMode !== 'managed') throw new Error('Close-out is only valid for a managed worktree');
  if (usedCloseOutAuthorities.has(authority)) throw new Error('Direct Git close-out authority is single-use');
  usedCloseOutAuthorities.add(authority);
  revalidateAuthorizedCommitState(authority);
  const exact = exactAssignment(db, authority.worktreePath, authority.workspaceGuid, authority.providerRootSessionId);
  const headOid = (authority.evidence as ReconcileEvidence).headOid;
  if (worktreeHead(authority.worktreePath) !== headOid) throw new Error('Close-out HEAD changed since issuance; re-run /close-out');
  // Task 5 inserts: const recovery = snapshotResidualIfDirty(db, exact);
  if (exact.assignment.lifecycle_status === 'active') {
    const local = finalizeLocalCommit(db, exact.primaryCheckoutPath, exact.assignment, authority.worktreePath, headOid);
    return closeOutRelease(db, local.repositoryPath, local.assignment, undefined);
  }
  if (exact.assignment.lifecycle_status === 'ready_for_integration') {
    // frozen-no-rebase only reaches here (paused rebase handled by the Task-3 handler pre-verify).
    try { runGit(exact.primaryCheckoutPath, ['rev-parse', '--verify', `${freezeRef(exact.assignment.workspace_guid)}^{commit}`]); }
    catch { throw new Error('Ready repair lacks durable frozen finalization state'); }
    runGit(authority.worktreePath, ['update-ref', candidateRef(exact.assignment.workspace_guid), headOid]);
    const local = finalizeAttestedCandidate(db, exact.primaryCheckoutPath, exact.assignment, headOid);
    return closeOutRelease(db, local.repositoryPath, local.assignment, undefined);
  }
  if (exact.assignment.lifecycle_status === 'integrated') {
    // Persistent Case A / handler-continued integrated row: already integrated; go straight to release.
    return closeOutRelease(db, exact.primaryCheckoutPath, exact.assignment, undefined);
  }
  throw new Error('Close-out needs an active, ready, or integrated managed assignment');
}
```
Note: the `ready_for_integration` block mirrors `finalizeReconcile`'s ready branch (:1173-1182) up to its
`recycleFinalized`, substituting `closeOutRelease`. The `integrated` branch relies on the row already
being durably integrated (candidate ⊆ main); `closeOutRelease`'s proofs re-verify it.
